Créer une facture QR suisse étape par étape (conforme SIX)

4 octobre 2026 · facturio.ch

Depuis le 1er octobre 2022, toute facture suisse avec un lien de paiement doit porter une facture QR (QR-Rechnung) au lieu des anciens bulletins de versement orange et rouges. Une facture QR correcte permet à votre client de scanner et de payer en quelques secondes ; une facture défectueuse fait échouer le paiement. Voici comment la créer, étape par étape et conformément aux normes SIX.

Réunir les données requises par la facture QR

Commencez par le compte sur lequel l'argent doit arriver. Pour la plupart des factures, un IBAN suisse normal suffit ; vous n'avez besoin d'un QR-IBAN que si vous souhaitez la référence QR à 27 chiffres pour le rapprochement automatique des paiements.

Rassemblez ensuite les coordonnées du bénéficiaire — le nom de votre entreprise et une adresse entièrement structurée. Depuis fin novembre 2025, l'adresse doit être répartie entre rue, numéro, code postal, ville et pays, et non regroupée dans une seule ligne de texte libre.

Choisissez la référence. La plupart des indépendants associent un IBAN standard à une référence créancier (RF…) ou laissent la référence vide et utilisent à la place le champ de texte libre pour les informations supplémentaires.

Enfin, fixez le montant et la devise. Une facture QR est en CHF ou en EUR ; le montant peut aussi rester vide, mais pour une facture normale, il vaut mieux l'indiquer clairement afin qu'il n'y ait rien à deviner.

Générer le code QR suisse

Le code QR suisse n'est pas un code QR ordinaire. Il suit les Swiss Payment Standards (QR-IBC) et encode une série précise et ordonnée de champs que les applications bancaires suisses savent lire.

Ne le générez pas à la main ni avec un outil QR générique. Un générateur internet gratuit non certifié SIX peut produire un code qui paraît correct mais qui échoue lorsqu'une banque tente de le lire.

Utilisez une bibliothèque qui met en œuvre la norme suisse, ou mieux, laissez votre logiciel de facturation construire le code à partir de vos données de paiement enregistrées. Le code et le bulletin imprimé restent ainsi synchronisés.

La règle d'or : les données contenues dans le code doivent correspondre exactement au texte visible. Un IBAN, un montant ou une référence erronés dans le code rendent tout le bulletin invalide, même s'il paraît correct sur papier.

Mettre correctement en page la partie paiement

Une facture QR complète est une partie paiement de 210 sur 105 millimètres, imprimée avec la croix suisse dans les coins supérieurs et le code QR à droite.

Elle se divise en deux moitiés : à gauche, un récépissé que le payeur conserve, et à droite, une section de paiement qui porte le code QR et les données lisibles par machine.

Les deux moitiés doivent afficher les mêmes informations essentielles en clair — bénéficiaire, montant, devise et référence — afin que le client puisse vérifier le paiement à l'œil nu avant de scanner.

Si vous envoyez des factures par voie numérique, la partie paiement est généralement rendue comme une section du PDF, et non comme un bulletin séparé. Conservez la même mise en page et la même qualité de données que sur papier.

Vérifier avant d'envoyer

Avant que la facture ne quitte votre bureau, scannez le code QR avec une application bancaire sur votre téléphone. S'il est lu correctement et affiche le bon bénéficiaire et le bon montant, il fonctionnera aussi pour votre client.

Vérifiez le montant, l'IBAN et la référence par rapport à la facture elle-même. Un seul chiffre inversé dans le numéro de compte est la cause la plus fréquente d'un paiement rejeté.

Assurez-vous que chaque adresse des données est structurée — rue, numéro, code postal, ville —, car les lignes d'adresse combinées sont désormais rejetées par les banques.
