La QR-facture suisse, expliquée aux indépendants

15 septembre 2026 · facturio.ch

La QR-facture a remplacé les bulletins de versement papier et constitue le standard obligatoire des factures suisses depuis le 1er octobre 2022. Elle rassemble toutes les données de paiement dans un code QR tout en affichant les mêmes informations en clair en dessous.

IBAN ou QR-IBAN : lequel vous faut-il ?

La QR-facture accepte deux types de numéros de compte, et choisir le bon vous épargne beaucoup de configuration. Voici la version courte.

  • IBAN standard — votre compte bancaire habituel. Suffisant pour la plupart des indépendants et des PME.
  • QR-IBAN — un format d’IBAN spécial délivré par votre banque ou PostFinance, utilisé uniquement avec une référence QR à 27 chiffres.

Un IBAN standard est tout simplement votre compte bancaire habituel. Il suffit pour la plupart des indépendants et des PME et ne nécessite aucun accord particulier avec votre banque.

Un QR-IBAN est un format spécial délivré par votre banque ou PostFinance, utilisé uniquement avec une référence QR à 27 chiffres. Vous n’en avez besoin que pour un rapprochement des paiements entièrement automatisé à fort volume de factures.

Le point essentiel : vous n’avez pas besoin d’un QR-IBAN pour envoyer des QR-factures. Un IBAN standard convient parfaitement, et vous pouvez l’associer à une référence de créancier pour un rapprochement automatique si vous le souhaitez.

Les trois types de référence

Le champ de référence est ce qui permet de rapprocher automatiquement les paiements entrants des factures ouvertes. Il existe trois options, chacune adaptée à un volume différent.

  1. Référence QR — un numéro structuré à 27 chiffres. Nécessite un QR-IBAN. Idéale pour les volumes de factures élevés avec rapprochement automatisé.
  2. Référence de créancier (ISO 11649, SCOR) — une référence structurée RF… qui fonctionne avec un IBAN standard. Rapprochable automatiquement et comprise à l’international.
  3. Sans référence — vous utilisez plutôt le champ de texte libre "informations supplémentaires". Convient aux faibles volumes.

La référence QR est idéale pour les entreprises qui envoient de nombreuses factures et les rapprochent sans travail manuel. Son coût réside dans la mise en place du QR-IBAN qu’elle exige.

La référence de créancier (RF…) est la voie médiane : un rapprochement structuré avec un IBAN normal, sans configuration bancaire particulière. C’est la meilleure solution pour la plupart des indépendants.

La troisième option, sans aucune référence, convient aux faibles volumes où vous rapprochez manuellement et facturez rarement deux fois le même client. Utilisez plutôt le champ de texte libre "informations supplémentaires".

Les champs obligatoires

Une QR-facture scannable repose sur un petit ensemble de champs obligatoires. Chacun d’eux doit être correct.

  • Code QR suisse avec les données de paiement.
  • IBAN ou QR-IBAN du bénéficiaire.
  • Nom et adresse du bénéficiaire.
  • Montant et devise (CHF ou EUR).
  • Référence (selon le type ci-dessus).

Le code QR porte les données de paiement lisibles par machine, tandis que le bulletin visible affiche les mêmes informations en clair. Le client doit pouvoir vérifier chaque champ à l’œil nu.

Le contenu du code QR doit correspondre exactement au bulletin de paiement visible. Un IBAN, un montant ou une référence erronés rendent la facture invalide, même si elle semble correcte sur le papier.

Lorsque vous utilisez une référence structurée, cette référence doit aussi apparaître en clair sur le bulletin. La laisser uniquement dans le code est une erreur fréquente qui compromet le rapprochement automatisé.

Un point qui a changé récemment

Depuis les 21–22 novembre 2025, les QR-factures doivent utiliser des adresses structurées — rue, numéro de maison, code postal et ville dans des champs séparés. Les anciens modèles avec des lignes d’adresse combinées ne sont plus scannés de manière fiable.

C’est important, car un modèle peut encore imprimer une adresse lisible alors que les données sous-jacentes ne sont plus scannées. Le résultat imprimé ne suffit pas : les données doivent aussi être structurées.

Pour les factures en EUR, un second changement récent s’applique : depuis février 2026, seul un IBAN standard avec une référence de créancier ou des informations supplémentaires est autorisé — pas de QR-IBAN pour les factures en EUR.

Si vous importez des données clients depuis un CRM, un fichier CSV ou Excel, vérifiez les champs d’adresse combinés. Les séparer maintenant évite des ordres de paiement rejetés et des corrections manuelles ultérieures.
