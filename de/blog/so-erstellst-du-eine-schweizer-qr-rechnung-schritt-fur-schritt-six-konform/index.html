So erstellst du eine Schweizer QR-Rechnung Schritt für Schritt (SIX-konform)

4. Oktober 2026 · facturio.ch

Seit dem 1. Oktober 2022 muss jede Schweizer Rechnung mit Zahlungsverbindung eine QR-Rechnung tragen — statt der alten orangen und roten Einzahlungsscheine. Eine korrekte QR-Rechnung sorgt dafür, dass dein Kunde in Sekunden scannt und bezahlt; eine fehlerhafte lässt die Zahlung scheitern. So erstellst du sie Schritt für Schritt und SIX-konform.

Die Daten sammeln, die die QR-Rechnung braucht

Beginne mit dem Konto, auf dem das Geld landen soll. Für die meisten Rechnungen genügt eine normale Schweizer IBAN; eine QR-IBAN brauchst du nur, wenn du die 27-stellige QR-Referenz für den automatischen Zahlungsabgleich nutzen willst.

Dann sammle die Angaben zum Zahlungsempfänger — deinen Firmennamen und eine vollständig strukturierte Adresse. Seit Ende November 2025 muss die Adresse in Strasse, Hausnummer, PLZ, Ort und Land getrennt sein und darf nicht mehr in einer einzigen Freitextzeile stehen.

Entscheide dich für die Referenz. Die meisten Freiberufler kombinieren eine normale IBAN mit einer Gläubigerreferenz (RF…) oder lassen die Referenz leer und nutzen stattdessen das Freitextfeld für zusätzliche Informationen.

Lege zuletzt Betrag und Währung fest. Eine QR-Rechnung ist CHF oder EUR; der Betrag kann auch leer bleiben, aber für eine normale Rechnung solltest du ihn klar angeben, damit nichts zu raten bleibt.

Den Swiss QR Code erzeugen

Der Swiss QR Code ist kein gewöhnlicher QR-Code. Er folgt den Swiss Payment Standards (QR-IBC) und codiert eine feste, geordnete Reihe von Feldern, die Schweizer Banking-Apps lesen können.

Erzeuge ihn nicht von Hand und nicht mit einem generischen QR-Tool. Ein kostenloser Internet-Generator ohne SIX-Zertifizierung kann einen Code liefern, der richtig aussieht, aber scheitert, wenn eine Bank ihn liest.

Nutze eine Bibliothek, die den Schweizer Standard umsetzt, oder noch besser: Lass deine Rechnungssoftware den Code aus deinen hinterlegten Zahlungsdaten bauen. So bleiben Code und gedruckter Schein synchron.

Die goldene Regel: Die Daten im Code müssen exakt mit dem sichtbaren Text übereinstimmen. Eine falsche IBAN, ein falscher Betrag oder eine falsche Referenz im Code macht den ganzen Schein ungültig — selbst wenn er auf Papier korrekt aussieht.

Den Zahlteil richtig anlegen

Eine vollständige QR-Rechnung ist ein Zahlteil von 210 mal 105 Millimetern, gedruckt mit dem Schweizer Kreuz in den oberen Ecken und dem QR-Code rechts.

Er ist in zwei Hälften geteilt: links ein Empfangsschein für den Zahlenden, rechts ein Zahlteil mit dem QR-Code und den maschinenlesbaren Daten.

Beide Hälften müssen dieselben Kernangaben im Klartext zeigen — Zahlungsempfänger, Betrag, Währung und Referenz —, damit der Kunde die Zahlung vor dem Scannen prüfen kann.

Wenn du Rechnungen digital verschickst, wird der Zahlteil meist als Abschnitt des PDF dargestellt, nicht als separater Schein. Behalte dabei dasselbe Layout und dieselbe Datenqualität wie auf Papier.

Prüfen, bevor du sie verschickst

Bevor die Rechnung dein Büro verlässt, scanne den QR-Code mit einer Banking-App auf deinem Handy. Liest er sauber und zeigt den richtigen Zahlungsempfänger und Betrag, funktioniert er auch bei deinem Kunden.

Gleiche Betrag, IBAN und Referenz mit der Rechnung selbst ab. Eine einzige vertauschte Ziffer in der Kontonummer ist der häufigste Grund, warum eine Zahlung zurückkommt.

Prüfe, dass jede Adresse in den Daten strukturiert ist — Strasse, Hausnummer, PLZ, Ort —, denn kombinierte Adresszeilen werden von Banken inzwischen abgelehnt.
