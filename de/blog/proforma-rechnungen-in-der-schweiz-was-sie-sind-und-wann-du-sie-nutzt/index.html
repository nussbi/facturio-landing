Proforma-Rechnungen in der Schweiz: Was sie sind und wann du sie nutzt

24. September 2026 · facturio.ch

Eine Proforma-Rechnung ist ein vorläufiges Dokument — eine Offerte in Rechnungsform. Sie wird für Zollanmeldungen, Vorauszahlungen oder dann verwendet, wenn ein Kunde vor der Zusage eine formelle Preisbestätigung braucht.

Proforma vs. echte Rechnung

Eine Proforma-Rechnung muss klar als solche gekennzeichnet sein und sollte nicht deine normale Rechnungsnummer tragen. Sie ist ein Entwurf oder eine Offerte, keine Zahlungsaufforderung.

Eine Proforma-Rechnung löst weder MWST noch eine Buchung aus. Es wird nichts gebucht, bis die echte Rechnung ausgestellt ist und das Geschäft tatsächlich stattfindet.

Die echte Rechnung ist es, die die Verpflichtung und die Steuerfolge erzeugt. Die Proforma-Rechnung teilt die Bedingungen lediglich in einem vertrauten, rechnungsähnlichen Format mit.

Weil die beiden sich ähneln, ist die Kennzeichnung alles. Eine Proforma-Rechnung, die nicht als Proforma markiert ist, kann versehentlich für eine echte Rechnung gehalten und bezahlt oder gebucht werden.

  • Kennzeichne sie immer klar als «Proforma».
  • Verwende deine Rechnungsnummernfolge nicht wieder.
  • Stell eine echte Rechnung aus, sobald der Abschluss bestätigt ist.

Häufige Verwendungszwecke

Zollbehörden verlangen für internationale Sendungen oft eine Proforma-Rechnung. Sie erlaubt ihnen, die Waren zu bewerten und Zölle zu berechnen, bevor die eigentliche Handelsrechnung ausgestellt wird.

Kunden verlangen eine Proforma-Rechnung, wenn sie vor der Auslösung einer Bestellung eine interne Freigabe brauchen. Sie gibt ihrem Einkaufsteam ein formelles Dokument zur Genehmigung.

Eine Proforma-Rechnung wird auch genutzt, um eine Vorauszahlung anzufordern. Der Kunde kann gegen die Proforma-Rechnung zahlen, aber du stellst die echte Rechnung trotzdem aus, wenn der Abschluss bestätigt ist und das Geld fällig wird.

Für Offerten, die offiziell wirken müssen — Ausschreibungen, Förderanträge oder Partnereinreichungen — liefert die Proforma-Rechnung das Rechnungsformat ohne das rechtliche Gewicht einer echten Rechnung.

Sie auseinanderhalten

Verwende für Proforma-Dokumente einen eigenen Nummernkreis, etwa PF-001, damit sie nie mit deiner echten Rechnungsfolge kollidieren können. Das allein verhindert die meisten Verwechslungen.

Nimm keine Zahlungsangaben auf, die eine Forderung nahelegen. Eine Proforma-Rechnung darf einen Preis zeigen, sollte aber nicht wie eine sofort fällige Rechnung klingen.

Wenn du dieselbe Vorlage für Proforma- und echte Rechnungen verwendest, füge ein sichtbares Wasserzeichen oder einen Banner wie «Proforma — keine Zahlungsaufforderung» hinzu, damit die beiden sofort unterscheidbar sind.

Schule alle, die deine Dokumente bearbeiten, die Kennzeichnung zu prüfen. Der häufigste Fehler ist, dass eine Proforma-Rechnung in die Buchhaltung geht und gebucht wird, als wäre sie eine echte Rechnung.

In eine echte Rechnung umwandeln

Wenn der Kunde bestätigt, stell eine echte Rechnung mit einer ordentlichen Nummer aus deiner Hauptfolge aus. Die Proforma-Rechnung ist dann erledigt, und das echte Dokument übernimmt die Buchhaltung.

Die echte Rechnung sollte ihr eigenes Rechnungsdatum tragen und, falls zutreffend, das Leistungsdatum bzw. den Leistungszeitraum. Diese können von der Proforma-Rechnung abweichen, besonders wenn der Abschluss erst Wochen später bestätigt wurde.

Wenn der Kunde gegen die Proforma-Rechnung bereits vorausbezahlt hat, sollte die echte Rechnung die Vorauszahlung als Abzug ausweisen, sodass nur noch der Restbetrag fällig ist.

Verweise auf der echten Rechnung auf die Proforma-Nummer, damit die beiden Dokumente verbunden sind. Ein kurzer Hinweis wie «gemäss Proforma PF-014» hält die Papierspur vollständig.

  • Verwende einen eigenen PF-Nummernkreis.
  • Füge ein klares «Proforma»-Wasserzeichen oder einen Banner hinzu.
  • Stell die echte Rechnung bei Bestätigung mit einer normalen Nummer aus.
  • Rechne eine allfällige Vorauszahlung auf der echten Rechnung an.
